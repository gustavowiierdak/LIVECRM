titulo: Atendimento web aceita o endereço da rede local
---

Em instalações locais, a configuração do atendimento web aceita a origem HTTP do próprio computador quando ela usa localhost ou um IP privado. A tela oferece preencher o endereço atual sem incluir caminhos; endereços públicos continuam exigindo HTTPS.
